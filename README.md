# Power-Board-Back-Up-Files
Power Board Backup
A board that holds premade DC DC converters and has capacitors for power safety proportional to the in and expected out voltages and currents of the converters.  There are terminals to connect to the battery and pins out for connection to the rest of the system.  This is 1/3 PCBs for the system.
